# Linux-Bench-Hub Roadmap

Linux kernel and server benchmarking orchestration roadmap.

## v1.1 — Automated Suite Runner

- **Automated Workload Dispatch**: Reproducible benchmark pipelines for CPU, memory bandwidth, and disk I/O.
- **Deterministic Hardware Telemetry**: Low-overhead hardware counters and thermal throttling monitoring.

## v1.2 — Interactive Performance Dashboard

- **Cross-Kernel Comparison Engine**: Automated diffing of regression traces across kernel versions.
- **Perfetto / FlameGraph Integration**: Trace visualization export for kernel bottlenecks.

## Out of Scope

- Synthetic non-workload benchmark gaming
- Manual unscripted testing procedures
