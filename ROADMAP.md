# Linux-Bench-Hub Roadmap

Plans for Linux kernel and server benchmarking.

## v1.1 — Automated Suite Runner

- [x] **Automated Workload Dispatch**: Run reproducible CPU, memory bandwidth, and disk I/O benchmark pipelines.
- [x] **Deterministic Hardware Telemetry**: Monitor hardware counters and thermal throttling with low overhead.

## v1.2 — Interactive Performance Dashboard

- [x] **Cross-Kernel Comparison Engine**: Compare regression traces across kernel versions.
- [x] **Perfetto / FlameGraph Integration**: Export trace visualizations for kernel bottlenecks.

## Out of Scope

- Synthetic non-workload benchmark gaming
- Manual unscripted testing procedures
